# E-Learning Website

## About the Project
E-Learning Website is a web-based application that provides course information and course details to users.

## Technologies Used
- HTML
- CSS
- JavaScript
- Java
- JSP
- JDBC
- MySQL

## Key Features
- Displays available course information.
- Provides course details through a web interface.
- Uses Java and JSP for dynamic web pages.
- Connects to MySQL database using JDBC.

## Project Type
Academic Project
