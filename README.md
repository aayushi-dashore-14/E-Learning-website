# E-Learning Website

## Project Overview
A web-based E-Learning application developed using Java, JSP and MySQL to display and manage course-related information.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java, JSP
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **IDE:** NetBeans
- **Build Tool:** Apache 

## Prerequisites
- Java JDK
- NetBeans IDE
- MySQL Server
- MySQL JDBC Driver
- Git

## Clone Repository

```bash
git clone https://github.com/aayushi-dashore-14/E-Learning-website.git
```

## Setup Instructions

1. Open NetBeans IDE.
2. Select **File → Open Project**.
3. Open the cloned project folder.
4. Start your MySQL server.
5. Create the required database.
6. Configure the JDBC URL, username and password in the project.
7. Ensure the MySQL JDBC driver is available in the project libraries.

## Run the Application

1. Open the project in NetBeans.
2. Select **Clean and Build**.
3. Click **Run Project**.
4. Open the application in your browser using the local URL provided by NetBeans.

## Build Configuration
The project uses Apache Ant through the `build.xml` file.
